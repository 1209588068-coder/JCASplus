# JCAS 方法能力与对照审查（2026-09-14）

## 审查范围与结论

本地公开 AV2、自训练车辆 pair 风险 GNN 的授权离线鲁棒性研究。
本轮只读现有源码、清单、结果和证据哈希；没有训练、图数组读取、新模型评估或 test
访问。保留全部冻结实验和失败结果，没有修改已有训练入口。

核心结论：当前缺少的是**在原数据投毒能力下，候选轨迹方法相对公平随机触发器的
有效证据**。不是已经证明随机触发器与设计方法相同，更不是修改 victim 后即可补足
这种证据。最近支路实验提供机制线索，但不是完整新投毒方法。

## 一、能力边界：最终改了什么，与离线设计知道什么，要分开

| 实验线 | 最终训练数据干预 | victim 训练／结构干预 | 证据身份 |
|---|---|---|---|
| v6.0 | 历史轨迹、目标 pair 标签、特征重算 | 预定 GENConv 和普通 BCE | 冻结正式主结果 |
| v6.4-S 与随机 pair 对照 | 相同触发器下改变训练 pair 规则 | 在两者共同的 42D 固定管线下普通 BCE | 冻结 development 与单种子对照 |
| relational BCE pilot | 固定共享模板；部分标签翻转、部分保留标签的控制；可选几何共同平移 | 各组固定 42D GENConv、普通 BCE、完整场景替换训练 | 数据投毒机制 pilot，不是完整学习式新方法 |
| 解码器配对 | 高频回放同场景 clean/full/reversed | 冻结编码器、直接训练解码器，改变采样／训练流程 | 训练机制诊断 |
| 运动支路、KL、上下文、中心化 | 小样本配对回放 | 新支路、冻结原 GNN、额外保持损失 | 结构与训练机制诊断 |

注意两点：

1. v6.4-S 相对 v6.0 同时改变 42D 表示和低速优先，因此两者不是单变量比较。
   “数据投毒实验”需相对于每条实验固定的 victim 管线定义；不能把攻击者修改 victim
   表示的自由度隐去。随机 pair 对照与 v6.4-S 则确实共同使用同一 42D 管线。
2. data-only 描述最终干预，不等于离线设计阶段完全不能用模型。v6.0 manifest 明确
   继承 train-only strict-crossfit 替代模型评分选择的 pair；公共评估目标池不以 victim
   输出筛选是另一条独立要求。不能把这两件事混称“全流程无模型黑盒”。

后续如继续原投毒研究，可在明确披露的 train-only 替代模型上研究可学习性；但最终
victim 必须按预定结构、损失、采样和 checkpoint 规则训练，不能要求它安装新支路、
执行攻击者定义的 KL、配对重采样或梯度操作。损失／模型改造若作为独立研究，必须
单列干预能力，不能悄悄扩大主实验设定。

## 二、四类对照不能互相代替

| 对照 | 真正改变的变量 | 回答的问题 | 不能据此声称 |
|---|---|---|---|
| 随机 pair | 哪对车辆被投毒 | pair 筛选是否有增益 | 随机轨迹触发器同样有效 |
| 随机共享触发器 | 固定轨迹模板的随机生成参数 | 设计／学习模板是否优于该随机模板分布 | 只与一个坏随机种子比即可证明一般优势 |
| 单端／方向反转 | 给定完整模板的某个结构关系 | 是否依赖双端关系、是否具有方向选择性 | 已经比较了随机触发器 |
| 支路输入／结构消融 | victim 的表示、读出或保持约束 | 模型如何利用方向／上下文信息 | 原数据投毒方法已提升 |

随机模板应在训练前固定，并在该次训练及对应评估中保持一致。每次输入都重新生成
独立随机噪声不是共享随机触发器的等价对照；可以另列，但不能用来替代主要基线。
不能为了得到论文所需差距而削弱随机对照，模块数量也不是贡献证明。

## 三、从当前资产重新核对的重要事实

### 3.1 随机 pair 并没有把全部训练目标换掉

来源：`record/reproduction/v6_4_random_pair_control/seed20260621_dfxklaqf/`。
对训练 manifest 的 scenario 和无序 track pair 独立重算，而非只引用 summary：

- 场景总数 5,776，112,179 个合格候选 pair。
- 两规则选中同一 pair：5,253 场景，**90.9453%**。
- 真正改变 pair：523 场景，**9.0547%**。
- 有两种速度类别候选的场景为 1,937；只有一种类别为 3,839。
- 随机规则选中 4,444 个低速 pair、1,332 个运动 pair，仍明显以低速为主。

相同 seed 20260621、同一 validation 公共池的已保存结果：

| 方案 | 整体 Incremental ASR | 低速 Incremental ASR | 运动 Incremental ASR |
|---|---:|---:|---:|
| 低速优先 | 62.5789% | 81.6322% | 0.0503% |
| 全合格随机 | 62.1438% | 81.0646% | 0.0503% |

正确结论：这次取消低速优先带来的差异很小，不能把低速优先当主要性能来源。
但它只改变了 9.05% 场景的 pair，不等于彻底替换整个训练目标分布，也不是对任意
pair 策略的统计等效证明。原三种子低速均值 83.78% 不能用作此单种子配对基线。
较早复杂 selection/random 消融的历史汇总同样不支持夸大排序贡献；已清理的扩展
产物不能在本轮声称重新复算。

### 3.2 Relational 仍未训练出新的优化模板

源码 `jcas/core/relational_trigger.py::template_bank` 生成 legacy_ramp 和三个固定随机
模板。`relational_bce_pilot.py` 固定选择 `random_20260912`，未按结果选择模板。
训练组 `random_shared` 与 `geometry_shared` 使用同一个模板；后者仅启用几何共同
平移控制器。协议明确记录 `template_optimized=false`、
`predictive_controller_optimized=false`、`full_module_C_implemented=false`。

所以当前三模块设想的实际状态是：

- A：共享平滑轨迹参数化、预算归一化已实现；学习式模板优化未实现。
- B：邻接距离变化的几何控制原型已实现；模型预测副作用优化未实现。
- C：跨场景普通训练下的学习式优化未实现。

不能把后来的支路学习误当作模板／模块 C 的完成。

### 3.3 几何控制器尚未证实预测副作用改善

只读此前已完成的 `bce_pilot/audit_73zxno25/comparison.csv`，没有重开 inner-audit 图。
以下是 836 个 train-inner audit 目标，不是其他实验的 validation 公共池：

| 训练／评估配置 | 整体 Incremental ASR | 运动 Incremental ASR | 相邻增量 FP |
|---|---:|---:|---:|
| 固定模板，无几何控制 | 44.8565% | 0% | 0.7435% |
| 同一模板，有几何控制 | 50.1196% | 0.4854%（1/206） | 1.2356% |

整体响应高 5.2632 个百分点，但相邻 FP 也更高，不能说几何控制已降低预测副作用。
几何能量改善是接受规则保证的数值结果，不等于分类 FP 改善。
在同一 geometry_shared 权重上，仅关闭评估时控制器，整体 ASR 为 49.7608%，
与开启的 50.1196% 很接近；这不等价于移除训练阶段的控制器，二者不能混为一谈。
完整与反转 Incremental ASR 为 50.1196% 与 46.8900%，方向选择性仍弱。

### 3.4 预算也不完全相同

Relational construct 实际使用 84,023 个有监督场景：

- 正向标签翻转 3,249 场景：**3.8668%**。
- 保留标签的负控制 810 场景：**0.9640%**。
- 总受控场景 4,059：**4.8308%**。

这不是旧方案的 5% 全正向投毒；也不能只用 92,457 个清单图作为实际训练分母。
新随机模板用 90% 增量预算份额，legacy ramp 用 100%；不同模板实际能量不保证相同。
因此不能把 relational 50% 与正式 v6.0 62% 或低速 84% 直接相减归因于模板好坏。

后期支路每步最多 1024 正常边＋384 辅助有向边，目标场景反复抽样；不是原来 5%
场景替换实验。即使都写普通 BCE，也不能说训练曝光预算一样。

## 四、哪些结果能保留为什么证据

- v6.0：唯一冻结正式主结果；本轮不重开 test，只沿用冻结报告身份。
- v6.4-S：慢速适用域的 development 结果，完整池与低速子组分开报告。
- 随机 pair：说明这项低速优先选择的边际贡献有限。
- Relational BCE：说明当前固定模板和几何控制在普通数据投毒下的响应与局限。
- 原始有符号特征／探针：方向信息存在的线索；探针 AUC 不是 victim ASR。
- v5 上下文支路：方向选择性改善但仍损伤正常预测的机制证据。
- 中心化：当前固定配置失败；不延长或挑有利单指标重新包装。

反转低激活是“关系选择性”主张的要求，不是所有后门风险实证都必须达到的定义。
若要继续主张关系选择性，应保留预注册门槛，不能因失败临时改口；若改研究问题，
应独立立项并继续披露本次失败，而不是补改本轮 gate。

## 五、后续方法与公平比较契约（建议，尚未运行）

1. 最终仅交付修改后的训练数据／清单与同一触发规则；victim 不新增支路或损失。
   离线替代模型的访问权限、拟合分组和查询／优化预算单独记录，不使用最终 victim
   或冻结 test 选择触发器。
2. 固定场景、pair、正向与负控制数量、两端位移和速度／加速度／jerk 预算、表示、
   模型训练过程、阈值和公共目标池；分别报告实际正投毒率与总变换率。
3. 模板对照固定为“候选模板 vs 同参数化的共享随机模板分布”，不能混入 pair 差异。
   随机模板种子在结果前固定，报告全部种子和分布。若候选经过搜索，随机搜索基线
   也应有匹配设计预算；不拿搜出的候选只比一个随手随机种子。
4. 几何控制器是另一个独立因素：候选／随机 × 控制器开／关的配对设计，用来区分
   模板收益、控制器收益及两者交互。只有满足预测副作用目标才可主张 B 的贡献。
   不是立即授权这四组训练；先有候选依据再冻结协议。
5. 关系反转／单端作为条件控制另报；正常参考模型的触发响应、实际扰动能量和动态
   标签语义另审计。保留 future 标签不等于车辆动力学或观察—未来连续性已认证。
6. 开发只使用 construct/develop。已使用的 inner-audit 不是新的盲测资源；原 test
   不动。多 seed、公平配对比较与 recording 聚合不确定性需要另行规划。

## 六、下一项应做什么

停止添加 victim 支路。先做**数据条件匹配的输入可分性审计**，而不是立即给另一个
网络结构起名字：

- 使用 construct 内 recording 分离的样本，分别匹配两端速度、pair 距离、径向
  接近速度、城市和局部图规模等可用数据条件；覆盖慢速与运动目标，报告匹配失败与
  保留覆盖率，不删除难例后冒充公共池结果。
- 在预定 victim 的原始可用表示中比较完整、反转、自然未触发和固定共享随机模板。
  匹配与模板生成不使用 victim 输出；推理表示不得依赖同场景 clean 相减的 oracle。
- 这回答此前探针差异是否部分来自基础运动／风险分布差异，而非模板关系本身。
  不同模板平均能量不一致时先披露或作可行的匹配，不能只宣称相同最大位移就公平。
- 原始几何特征、动态标签一致性和观察—未来衔接是前置检查。可分性仅是必要线索，
  不能直接作为放行 ASR gate；也不应为找到高探针分数无限搜索模板。

这是一项新审计建议，不是已完成新方法，不保证有优于随机的模板。若条件匹配后仍
找不到独立结构信号，应停下并收敛为现有脆弱性与局限结论，而非人为削弱随机基线。
若出现可复现信号，才据此定义 train-only 模板设计／优化变量；它必须明确区别于
此前失败的 adaptive、DCT、codeword、moving-only 等方向，不能只换名称重做。
