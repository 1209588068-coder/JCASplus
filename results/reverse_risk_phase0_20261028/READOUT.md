## 反向指标合同

固定原始标签为 1 的公共池，大小 N；同一 victim 的干净/触发预测配对比较。
令 TP 为干净输入识别正确的正类数，FN 为原有漏报数，I 为新增 1→0 漏报数，
R 为原有漏报被修正的 0→1 数：

- Incremental ASR = I/N。
- Conditional suppression = I/TP；TP=0 时为未定义，而不是 0% 或 100%。
- Absolute suppression = (FN+I−R)/N。
- 净漏报增加 = (I−R)/N。
- 始终同时报告 FN/N、分子分母、Slow/Moving 和正常任务 AUC/正类召回。

对一个固定模型和固定池，Incremental ASR 最大为 TP/N，即该模型的干净正类召回。
因此不能沿用正向 80% 的整体 Incremental ASR 门槛，也不能把条件抑制率称为整体 ASR。
此上限必须按未来新训练的反向 victim 重算；上表不是未来模型的固定上限。

## 下一步：独立反向单种子 pilot（尚未实现或启动）

研究问题：在正常识别能力不显著退化的条件下，共享的派生特征模式能否让原本被正确识别的
风险 pair 新增漏报？仅调换攻击方向本身不构成新的算法创新。

1. 固定原 train512/dev128、原 1,876 个正常监督索引、784 维表示、24 维支持、
   GraphSAGE 与预算。另行登记正类附件 26 个及额外 outer 512 个；不根据 dev 预测筛训练点。
2. 新建反向入口及契约，不放宽正向代码的 target=1/negative attachment 防护。
   训练目标使用 class 0；评估真值仍为原标签 1。派生特征边界不变，不称为真实轨迹扰动。
3. 配置同一新监督集合（原 1,876 + 新 26）的 matched clean control，保留原始特征及标签；
   不能只把基于旧 26 个负类附件训练的 clean reference 当作匹配对照。
4. 加入同样监督集合、仅翻转附件标签但不加共享特征模式的对照，检查效果是否只是标签污染。
   对照与反向 victim 使用相同初始化种子、训练预算和 clean dev AUC 检查点规则。
5. 当前 start generator/surrogate 带有正向预训练历史。第一轮若复用，必须明确命名
   “正向起点的反向续训”，不能用该结果推断两个方向的固有难度或声称从头反向复现。
   从头、方向对称的比较属于后续单独实验，不能与续训结果混写。
6. 分布参考重新绑定新的正类 outer；分布判别器按登记种子重新初始化。
   双 clean-proxy KL 仍是干净分布保持约束，不交换概率列；代理不是独立评测模型。
7. 开跑前锁定适用于反向的新门槛。建议正常任务 AUC 相对匹配 clean 下降不超过 0.005、
   正类召回下降不超过 0.05；非目标正类新增漏报、负类误报分别报告，不用正向邻接 FP 掩盖风险。
   条件抑制率、整体增量、净漏报增加都报告；不得只选有利口径，也不得事后调阈值。
   “比匹配 clean 和仅翻标签对照有收益”的计数/门槛仍需在 pilot 计划中正式登记。

若未加触发时模型已通过普遍输出 0 降低风险召回，不能称作低副作用的成功。
候选充足只表示可以进入上述 pilot 的实现与预注册，不等于反向方法已有效。
