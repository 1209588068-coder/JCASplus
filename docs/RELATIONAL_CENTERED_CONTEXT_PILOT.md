# 中心化上下文支路：固定单种子机制实验

本地 AV2、自训练 GNN 的授权离线鲁棒性研究。不是冻结 v6.0，也不是原仅数据投毒能力
下的新主结果。本文件中的机制版本 v6 与冻结主实验 v6.0 无关。

## 假设与唯一结构变化

v5 固定权重诊断发现：纯上下文分数变换有正常召回损伤，而运动／上下文交互有方向
区分线索；直接删掉已训练模型的纯上下文项会恢复正常召回，但反转激活升高。
本轮从头训练，检验是否能在缺少这条捷径时学会足够的方向抑制。

两组共享 9→32→1 SiLU 架构、初始参数、construct 标准化和样本顺序，都启用上下文：

```text
uncentered_context: base + 8*tanh(h(m,c)/8)
centered_context:   base + 8*tanh((h(m,c)-h(0,c))/8)
```

m/c 是标准化并夹断后的运动／基础 logit。参考运动 0 是 construct 均值，不是实际
静止轨迹；c 为相同输入的基础 logit，不是对应干净场景的 oracle 分数。
两条 h 路径均参与求导，不 detach 参考输出。相减在 tanh 前进行，最终修正保持 ±8。

在参考运动处严格零修正；不能保证所有正常运动输入都零修正。中心化消掉输出 bias
作用，名义参数数目相同但有效自由度略有差异。禁止宣称上下文不再能影响正常预测。

## 不变的设置和门槛

- 固定原 geometry_shared 全部 GNN 权重，不续训 v5 支路。
- seed 20260621；两组相同初始化，末层和 context 新增列零初始化。
- construct 337 低速辅助场景、923 正常图／40,536 有向边。
- 1024 正常边＋64 辅助场景×3 条件×2 方向；辅助标签 0/1/0。
- mean BCE＋1.0×正常 Bernoulli KL；lr=0.003、weight_decay=1e-4。
- 每组 10 epochs、400 更新，只取最终 checkpoint，不搜索超参数。
- 相同原 train 内 develop：64 低速目标＋64 运动观察目标、21,143 正常 pair。
- 门槛：低速完整 Incremental ASR≥60%，反转绝对激活≤10%，干净 AUC 下降≤0.0015。
- 副作用、正常正负类变化、相对控制组的 full-only 差异另行报告。
- 不访问 inner-audit 或原 validation/test，不覆盖历史记录；无论结果均不自动扩展任务。

当前 GPU 有其他研究进程，本轮两组均显式使用 CPU、4 线程。设备记录在 protocol 和
summary 中。相对于此前 GPU 结果可能存在浮点差异，主要比较本轮同设备两组。

## 实现与输出

`jcas.workflows.relational_centered_context_pilot` 提供 `--check-only` 和 `--run --device cpu`。
本轮由助手执行，不需要用户运行命令。新目录前缀：
`record/reproduction/relational_poison_v1/bce_pilot/centered_context_*/`。

保存协议、样本、两组 checkpoint/history、逐目标响应、干净 pair 分数、副作用、gate
和 SHA 汇总。训练结束验证：重载输出一致、中心化参考运动零修正、基础 GNN SHA 未变。
正常完成但 STOP 返回 2；不能将其误认为运行异常。

正式结论必须同时报告关系选择性、正常预测损伤和副作用；内部 develop 已反复用于
开发，不能当作独立泛化证据，更不能据此声称胜过随机触发器。

## 已执行与独立复核结果

输出：`record/reproduction/relational_poison_v1/bce_pilot/centered_context_9kfjqmpi/`。
两组 CPU 各 10 epochs、400 次更新完整结束，状态
`CENTERED_CONTEXT_COMPLETE_REVIEW_REQUIRED`，gate **STOP**。没有后续训练任务。

新增 7 项测试，全套 310 项通过。逐 pair 正常指标、逐目标响应、副作用、gate 和
证据 SHA 均独立复算；重载两组 checkpoint 复现 construct 预测，中心化组训练后
在参考运动处仍严格等于基础 logit。基础 GNN SHA、冻结源码归档和 grouped-v5
manifest 未变。普通上下文 CPU 对照的 AUC、召回、精确率、F1 及主要触发计数
复现了 v5 GPU 结果，概率尾数存在微小设备差异。

以下触发结果来自 64 个低速内部 develop 目标，正常指标来自 21,143 个正常 pair：

| 指标 | 普通上下文 | 中心化上下文 |
|---|---:|---:|
| 完整 Incremental ASR | 73.4375% | 75.0000% |
| 反转绝对激活率 | 17.1875% | 35.9375% |
| 完整激活、反转不激活 | 57.8125% | 40.6250% |
| 干净 Pair AUC | 0.984007653 | 0.977455524 |
| 干净正类召回 | 80.2442% | 82.2939% |
| 干净负类 FP | 1.1830% | 1.5862% |
| 低速完整触发 adjacent incremental FP | 2.0107% | 1.6086% |

原 GNN 干净 AUC=0.987063291、正类召回=83.5150%、负类 FP=1.0928%。
候选 AUC 下降 0.009607767，明显超过 0.0015；反转激活率超过 10%。
另 64 个运动观察目标的 Incremental ASR 为 6.25%（4/64），不是已解决运动目标问题。

### 解释与停止决定

中心化使完整触发新增翻转多 1 个，但反转激活多 12 个；不能以 ASR 小升认定进步。
它减轻了部分正常正类压分，却增加负类误报并损害整体排序，未实现整体正常保持。
最终训练 mean BCE/KL 也从控制组 0.171191/0.013899 变为
0.196390/0.026644，当前固定预算下并非只在 develop 上出现退步。

中心化约束本身经过恒等式验证，问题不在“没有真正取消纯上下文项”。约束只固定
参考运动处的输出，不保证真实正常样本的修正小，也不保证跨场景排序保持。
不能据此断言所有中心化方法不可能成功，但本次固定参考点／训练配置没有改善目标。

停止这项中心化配置，不扩种子、不延长 epoch、不扫描参考点或 KL 权重。
v5 仅保留为较好的方向选择性机制参考，它仍未通过门槛，不能升级为正式方案。
后续不应把一轮轮修改模型支路直接当作原数据投毒方法的优化证据；需要先审查研究
干预能力与最终目标，并为下一项候选给出独立依据和公平随机对照，而不是立即再开训练。
